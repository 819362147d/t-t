# 事件胜率优化报告（第二遍：纯毛胜率，不计摩擦）

> 本遍按用户明确要求**完全不计摩擦**，目标函数只有 `win_rate_gross`（10 分钟后方向对即赢，顺向涨幅 > 0）。它只回答“模型方向准不准”，不回答“赚不赚钱”。
> 一行提醒：毛胜率高不等于在现行 TP/SL 结构下能盈利，净口径结论见同目录 `REPORT.md`。

## 口径与纪律

- 数据：复用第一遍已回填并逐位校验过的数据集 `events_all.csv.gz`，17,717 个事件（2026-10-18 → 2026-11-01），事件步长 5 分钟（特征锚点定义在 5m bar 收盘，1 分钟事件不存在该定义），每事件带 31 个特征与 10 分钟结算结果。
- 切分：与第一遍完全相同的时间边界——先 60% 为搜索集（10,633 事件，5.27 天），后 40% 为验证集（7,084 事件，3.51 天）。所有扫描与搜索只在搜索集上做，候选冻结后原样在验证集评估。
- 样本下限：n ≥ 100 才作头条结论，未达标的数字一律标注。
- 本遍共执行约 **2,742 次配置评估**（基线/扫描/单特征/双特征/五分位/验证），多重比较规模与第一遍相当，打折方式相同。
- 方向口径：cutoff c 对称，prob ≥ c 做多、prob ≤ 1−c 做空；0.55 即现行 0.55/0.45。

## 二、概率阈值扫描（毛胜率）

合并集全扫描（搜索胜率 / 验证胜率 / 验证 n）：

| cutoff | 0.52 | 0.54 | 0.56 | 0.58 | ≥0.60 |
|---|---|---|---|---|---|
| 搜索 | 52.5% | 53.1% | 55.2% | 49.5% (n=93) | 样本枯竭 |
| 验证 | 50.8% | 51.5% | 54.1% | 54.6% (n=77) | 样本枯竭 |

- 搜索集选出的最优（n≥100 约束下）是 **cutoff=0.56**（搜索 55.2%，n=779），冻结后验证集只有 **54.1%**（n=484），**低于现行 0.55 的验证 54.9%**——与第一遍（净口径）结论一致：调阈值没有样本外增益，维持 0.55/0.45。
- 逐标的搜索选优 → 验证结果：BTC 0.56 → 57.1%（验证 n=70，未达下限）；XAU 0.54 → 57.4%（n=209，远低于 XAU 在 0.55 的 73.0%，放宽阈值反而稀释）；TSM 0.54 → 51.1%（n=272，明显变差）；USOIL 0.54 → 50.4%；QQQ 0.56 → 54.7%（验证 n=64，未达下限）；BNB/SPY 任何 cutoff 在验证集都 ≤48.7% / ≤47.0%。
- 仅作参照（在验证集上事后挑最优，不构成推荐）：合并 0.56 的 54.1% 已是验证集上的最高点之一；XAU 在 0.56 时验证 72.2% 但 n 只有 36，BTC 在 0.54 时验证 57.5%（n=240）。

## 四、特征方向性（五分位）与重要性

合并集信号内，按每个特征自身五分位分组看毛胜率（边界取自搜索集，验证段用同一边界）：

- 两段同向、稍有信息量的：`boll_pctB`（15m 布林位置）最低五分位搜索 58.6% / 验证 59.1%，最高五分位只有 51.9% / 51.2%——信号在价格贴近布林下轨时方向更准，带均值回归味道；`mom_10m`、`mom_30m` 同样是最低五分位（57.0% / 59.9%、58.3% / 56.7%）优于最高五分位（49.8% / 52.4%、50.5% / 51.0%），即短期跌幅大后模型方向更可信。
- 验证段看着大但搜索段不支持的（不采信）：`rsi14_1h` 最高五分位验证 70.0%，但搜索段两端几乎无差异（57.2% vs 57.3%）；`dow_sin` 验证价差 −13.0pt，是星期伪规律。
- 其余多数特征两端差异在 ±3pt 内且两段符号不一致，视为无稳定方向信息。

GBM 特征重要性（gain，前 8）：rsi14_5m（3800）、rsi14_1m（2210）、boll_pctB_1m（1149）、dow_sin（972）、boll_pctB_5m（965）、rsi14（719）、kdj_j_15m（593）、hour_cos（502）。注意 gain 高只说明模型在用它，不等于它单独能筛出高胜率——五分位表才是单特征方向性的直接证据，两者并不一致（例如 rsi14_5m gain 第一，五分位两端差异只有 −2.9pt 且符号两段不稳）。

## 六、本遍结论

1. 纯方向层面，模型是真有东西的：合并验证毛胜率 54.9%（z=+3.18），且不是靠单个标的撑起来的——XAU、BTC、TSM 三家两段同向为正。
2. 最强的单标的方向是 **XAU**：验证段双向都显著，73.0% 是全场最高且有统计支撑；BTC 的优势几乎全在多头一侧。
3. 阈值调整在毛口径下同样无样本外增益，维持 0.55/0.45。
4. 过滤规则在毛口径下没有找到强解：存活者只有 +1~+3pt 的弱提升，合并集双特征组合全灭。这与净口径那遍互补——能显著改善结果的过滤（mom_10m 波动门）改善的是“波动幅度”而非“方向命中”。
5. 本遍共评估约 2,742 次配置；验证窗只有 3.51 天，所有“存活”规则都只能算弱证据，需要更长的前向记录（实盘记录器正在积累）再确认。
