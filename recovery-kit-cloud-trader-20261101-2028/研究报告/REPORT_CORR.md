# 相关性研究报告（第三遍：多指标强相关寻找）

> 本遍问题只有一个：31 个指标里，到底哪些与结果（方向 / 涨幅）存在**强且稳定**的相关，
> 哪些指标彼此只是在重复测量同一件事。复用前两遍的数据集 `events_all.csv.gz`
> （17,717 事件，逐位校验过），同一切分（搜索 60% / 验证 40%），未重新回填、未下单。
> 合并集相关一律用**标的内排名**再合并（macd_hist 等特征带价格单位，跨标的直接合并无意义）。
> 稳定性规则（任务预设）：两段同号且都达到幅度门槛（全事件 |ρ|≥0.03、信号子集 |ρ|≥0.05），
> 且逐标的同号一致的标的 ≥4/7，才算"强相关"。相邻事件的 10 分钟结算窗互相重叠，
> 样本并非独立，名义显著性会被高估——本报告只认 ρ 的幅度和跨段/跨标的一致性，不报 p 值。

## 结论先行

1. **方向上不存在强相关。** 全事件层面只有 3 个指标与 ret10 的相关通过稳定性规则，
   且幅度都只有 |ρ|≈0.04、清一色负号（均值回归味）：`mom_10m`、`rsi14_1m`、`rsi14_1h`。
   互信息（非单调检查）最大值仅 0.004 bit——没有任何藏在非线性里的方向结构。
   信号子集上**没有任何指标**通过严格稳定性规则（对 win_gross 和方向收益都没有）。
2. **唯一真正强而稳的相关在"涨幅大小"上**：`atr_norm` 与 |ret10| 的 ρ 为
   **+0.335（搜索）/ +0.499（验证），7/7 标的同号**。波动状态决定"动多大"，不决定"往哪动"。
   这正是第一遍波动门（mom_10m/vol_z 过滤）能改善净胜率的统计根源——它们筛的是幅度，不是方向。
3. **双指标组合没有找到可交易的幸存者。** 共试 11,625 个五分位状态组合（n≥80 的 2,621 个进入评分），
   冻结前 12 名里唯一机械达标的组合含星期因子（见下），按前两遍同一证据标准判为日历伪规律；
   其余全部在验证段衰减或反转。深度-3 GBM 交叉验证给出验证段 **AUC = 0.498**（等于抛硬币），
   与网格搜索互相印证：信号子集上没有可样本外复现的双指标结构。
4. **31 个指标里有一半是同一个东西**：16 个震荡/动量类指标构成一个 |ρ|≥0.7 的连通冗余簇，
   其中 5m 与 15m 两组核心的相关高达 0.90+。所谓"多指标共振"，多数时候只是一个测量被重复了十几次。
   真正互相独立的信息轴只有几条：震荡复合体、atr_norm、vol_z、cvd_z 家族、x_mom（跨标的动量）、macd_hist、日历。

- 通过规则的 3 个全是**负相关**：过去 10 分钟涨得越多、RSI 越高，未来 10 分钟收益越偏负。
  这是短周期均值回归的统计签名，幅度 |ρ|≈0.04 意味着单指标对方向的解释力约 0.2% 的方差——
  真实存在，但弱到不可能单独作为过滤器（与第二遍五分位结论一致：只有极端五分位有约 +5pt 的胜率差）。

  TSM/SPY 上接近 0。模型的 prob 已经把这类信息吃进去了——这也是信号子集上再也榨不出东西的原因（见 A3）。
- 明确的假象样本：`kdj_j_15m` 与 `x_mom_1h` 两段翻号；`boll_pctB_5m` 搜索段 −0.065 看着最强，
  验证段只剩 −0.016。只看一段数据时，这几个都会被误报成"强相关"。
- 互信息 MI（特征十分位 × ret10 符号）前三：boll_pctB_5m 0.0043/0.0027 bit、
  rsi14_1m 0.0027/0.0030、rsi14_3m 0.0034/0.0025——量级可忽略，
  非单调结构同样不存在，不存在"线性看不见、非线性很强"的隐藏指标。

## Layer B：双指标状态组合（信号子集）

方法：每指标按搜索段自身五分位分档，组合 = 指标 i 在某档 且 指标 j 在某档（含同向/反向状态），
共 **465 对 × 25 状态 = 11,625 个组合**全部试过；搜索段 n≥80 的 **2,621 个**进入评分，
按胜率 lift 冻结前 12 名，原样在验证段评估。基线毛胜率：搜索 53.8% / 验证 54.9%。

冻结前 12（注：其中 dow_sin Q2 与 dow_cos Q2 在本数据上选出的是**同一批事件**，
hour_cos 两条同理，实际不同的组合只有 9 个）：

| 组合 | 搜索 n / 胜率 / lift | 验证 n / 胜率 / lift | 判定 |
|---|---|---|---|
| rsi14_1h Q5 且 kdj_j_15m Q4 | 81 / 72.8% / +19.0pt | **7** / 71.4% / +16.5pt | ❌ 验证样本枯竭，无意义 |
| boll_pctB_5m Q1 且 boll_pctB_1m Q2 | 81 / 70.4% / +16.6pt | 62 / 58.1% / +3.2pt | ❌ lift 衰减 80% |
| **boll_pctB_1h Q2 且 dow_sin Q2**（≡ dow_cos Q2 版） | 138 / 68.8% / +15.0pt | 142 / 63.4% / +8.5pt | ⚠️ 机械达标，但含星期因子 → **按伪规律处理，不采信** |
| hour_cos Q4 且 dow_sin Q2（≡ dow_cos 版） | 115 / 68.7% / +14.9pt | 87 / 59.8% / +4.9pt | ❌ 衰减 + 日历 |
| boll_pctB_1h Q2 且 hour_cos Q4 | 83 / 68.7% / +14.9pt | 86 / 59.3% / +4.4pt | ❌ 衰减 70% |
| rsi14 Q3 且 rsi14_5m Q4 | 92 / 68.5% / +14.7pt | 61 / 49.2% / **−5.7pt** | ❌ 反转，典型过拟合 |
| trend_score Q3 且 willr14_15m Q2 | 84 / 67.9% / +14.0pt | 95 / 56.8% / +1.9pt | ❌ 衰减殆尽 |
| rsi14 Q2 且 kdj_j_15m Q1 | 87 / 67.8% / +14.0pt | 118 / 60.2% / +5.3pt | ❌ lift 只剩 1/3，未达标 |
| boll_pctB_5m Q5 且 willr14_15m Q3 | 80 / 67.5% / +13.7pt | 48 / 56.2% / +1.3pt | ❌ 衰减殆尽 |
| rsi14 Q2 且 rsi14_3m Q1 | 95 / 67.4% / +13.6pt | 87 / 60.9% / +6.0pt | ❌ lift 未过半，未达标 |

**过拟合墓地小结**：12 个冻结组合里，1 个样本枯竭、1 个反转、8 个 lift 衰减 60% 以上、
1 个机械达标但靠星期因子。**非日历类幸存者：0 个。** 搜索段 67–73% 的胜率在 11,625 次
多重比较下本就是期望之中的尾部噪声，验证段把它们打回了 49–61%。

**GBM 交叉验证**（搜索段信号训练深度-3 LightGBM，200 棵）：验证段 **AUC = 0.498**，
预测最高十分位胜率 56.7%（n=104）vs 基线 54.9%——在噪声内（该组标准误约 ±4.9pt）。
其路径共现"交互"前列为 rsi14_1m×vol_z、cvd_z_1m×mom_30m、cvd_z_15m×mom_1h 等，
与网格搜索的冻结名单**无一对应**；在一个 AUC=0.5 的模型里，这些交互只能读作拟合噪声的形状，
不构成对任何组合的佐证。两个独立方法在同一问题上同时给出空结果，这个"空"本身就是结论。

## Layer C：指标间冗余（|ρ|≥0.7 的对子共 37 对）

全部 37 对都落在一个 **16 指标连通簇**内：

> boll_pctB、boll_pctB_1h、boll_pctB_1m、boll_pctB_5m、kdj_j_15m、willr14_15m、
> rsi14、rsi14_1h、rsi14_1m、rsi14_3m、rsi14_5m、trend_score、mom_10m、mom_30m、mom_1h、mom_4h

其中最紧的核心（ρ≥0.90）：rsi14_5m~rsi14_3m（+0.941）、boll_pctB_5m~rsi14_3m（+0.934）、
rsi14_5m~boll_pctB_5m（+0.912）、rsi14~boll_pctB（+0.909）、rsi14_1m~boll_pctB_1m（+0.904）、
boll_pctB~willr14_15m（+0.904）。即 RSI、布林 %B、KDJ、威廉指标在同一周期上本就是
同一价格位置的四种写法，跨周期（1m/3m/5m/15m）又彼此高度连动；mom 家族通过与 %B 的
0.74–0.82 相关被链进同一簇。该簇之外的独立轴：atr_norm、vol_z、cvd_z_1m/5m/15m、
x_mom_1h/4h、macd_hist、flip_long/short、abs_trend_score、hour/dow 日历组
（簇内两两并非都 ≥0.7，是经链式连接成连通分量；核心对见上）。

对解读的直接影响：Layer B 里凡是"震荡指标 × 震荡指标"的组合（如 rsi14 × rsi14_5m），
本质是同一状态的双重确认而非两个独立证据，其搜索段高 lift 更容易是同一噪声被数了两遍；
真正有资格叫"多指标"的组合应跨轴取材（如 震荡 × atr_norm / vol_z / cvd_z），
而本遍这类跨轴组合无一进入冻结前列。

## 底线：真正强而稳、值得记住的 4 条关系

1. **atr_norm → 涨幅大小：ρ +0.34 / +0.50，7/7 标的。** 本数据集里最强、最稳、机制最清楚的一条。
   它说的是"接下来 10 分钟能动多大"，与方向无关——用它做波动门/仓位缩放有据可依，
   拿它猜方向则完全用错了地方。
2. **短线动量/RSI → 方向：弱负相关（均值回归），ρ≈−0.04，两段同号。**
   mom_10m、rsi14_1m、rsi14_1h 三条过关，合计解释力仍不到 1% 方差；
   模型的 prob 已经包含这层信息，信号之后再叠同类过滤没有增量（Layer A3 + 第二遍已双重验证）。
3. **vol_z → 涨幅大小：ρ +0.14 / +0.06，7/7 同号但验证段减半。** 真实、二阶，
   与 atr_norm 方向一致、强度明显不及；波动门二选一时 atr_norm 的证据更硬
   （但第一遍实测 vol_z 组合的净胜率不差，两者口径不同：本遍看 |ret10| 相关，第一遍看净胜率结果）。
4. **星期/时段与涨幅大小相关显著但不可信。** dow_sin 两段 +0.24/+0.45 却被同族 dow_cos 的
   翻号（+0.14 → −0.42）拆台；8.8 天样本撑不起任何日历结论，前两遍的 dow 高胜率规则同罪。

一句话总括：**这套指标里，"波动状态→幅度"是强关系，"任何指标→方向"都是弱关系，
"双指标组合→胜率"在本样本内是空集，31 个指标的有效维度约等于 7–8 个。**
若后续还要找强相关，方向应是换信息源（盘口/资金费率/跨市场）或拉长周期，而不是在同一簇里继续排列组合。

## 局限

- 样本仍只有 8.8 天、验证窗 3.5 天；相邻事件结算窗重叠，相关系数的有效样本量低于名义值。
- Layer B 多重比较规模（11,625）远大于前两遍，冻结名单的搜索段数字必然严重高估，已用验证段打折。
- GBM 交互用"同路径共现×分裂增益"代理，非严格的交互强度（如 H 统计量）；但 AUC=0.498 已使该问题无实际意义。
- 机器可读结果：`runtime/event_optim/corr_results.json`；代码：`event_optim/analyze_corr.py`。
  本遍未下单、未用密钥、未触碰实盘与记录器进程。
