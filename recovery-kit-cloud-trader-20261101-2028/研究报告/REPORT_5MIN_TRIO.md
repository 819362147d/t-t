# 5 分钟事件合约研究报告（第五遍）：均值回归三指标方向对齐门 × 波动门

研究对象：cloud-trader 现行事件模型 + 7 标的，事件周期 **+5 分钟**（与第四遍同口径），
在第四遍 atr_norm / vol_z 波动门之外，把第三遍相关研究里唯一通过方向稳定性检验的
三个均值回归指标 `mom_10m`、`rsi14_1m`、`rsi14_1h` 做成**方向对齐门**叠加进来。
全程只读缓存 K 线，未下单、未用密钥、未触碰在跑的实盘与记录器进程。

> 本遍按既定口径只看毛胜率（win5 = 5 分钟后方向对即赢），不计摩擦——毛胜率高不等于能盈利。

---

## 一、结论先行

1. **答案仍是否定的：五个配置族没有一个在验证段跑赢无门基线。**
   基线验证 win5 = **52.5%**（n=1040）；五族冻结配置的验证 win5 分别是
   TRIO-VOTE **52.5%**（n=922）、FIVE-AND 52.0%（175）、TRIO-AND 51.9%（187）、
   TRIO-SCORE 51.2%（283）、FIVE-STRICT 50.4%（125）。五族的验证 95% CI
   全部跨过 50%，也全部包含基线值——与基线无统计差别，或更差。
2. **唯一"打平"基线的 TRIO-VOTE（tail=0.4）几乎等于没装门**：它保留了
   验证段 922/1040 = 89% 的信号（三指标里任意两个在最宽的 40% 尾内对齐，
   而这三个指标同属一个冗余簇、彼此高度相关，"任意两个对齐"本来就很容易满足）。
   门越严格（TRIO-AND / FIVE-STRICT），胜率反而越往下掉。
3. **剂量-反应不存在**：对齐个数 0/1/2/3 的验证 win5 = 52.9% / 53.4% / 52.6% / **51.7%**，
   基本是平的，且全对齐（3 个）反而是最低档；搜索段同样非单调（34.0%* / 51.0% / 53.0% / 51.9%，
   峰值在 2 个对齐而非 3 个）。"对齐越多越好"的假设被两段数据同时否定。
   （*搜索段 0 对齐桶 n=47 且平均 |ret5| 只有 0.021%，是极端安静的一小撮，不作解读。）
4. **三指标的方向相关是真的，但太弱、且已被模型吃掉**：第三遍测到的 ρ≈−0.04
   是全事件口径的统计事实；落到信号子集 + 5 分钟结算 + 门的形式后，
   残余 edge 测不出来。这与前四遍完全自洽——方向信息在 prob 里，
   外层再叠方向门只是把样本切碎。
5. **逐标的格局与前四遍一字不变**：表现最好的冻结族（TRIO-VOTE）下，
   XAU 67.9%、BTC 57.3%、TSM 56.7% 仍是前三，但与各自无门基线
   （66.3% / 57.4% / 57.0%）逐一对照几乎同值——是标的自身的方向强弱，不是门的功劳；
   SPY 42.6%、BNB 46.6% 继续垫底，维持原判决。

## 二、方法

- **数据**：复用 `events_all.csv.gz` 17,717 个事件（特征与 prob 与实盘逐位一致），
  ret5 与第四遍同法从 1m 缓存计算（锚点+4min 开盘 bar 的收盘 / entry − 1），
  本遍再次同法重算 ret10 对账，**最大偏差 = 0**，ret5 缺失 0。
- **信号/切分**：prob ≥ 0.55 做多、≤ 0.45 做空；ts 60% 分位时间界，
  搜索段信号 1,533 个（5.25 天）、验证段 1,040 个（3.51 天）。与前四遍完全一致。
- **方向对齐定义**（三指标均为负相关/均值回归，故对齐 = 处于与信号方向相反的极端态）：
  - 多头信号：`mom_10m`、`rsi14_1m`、`rsi14_1h` 各自 ≤ 该标的搜索段全事件分布的 tail 分位（刚跌过/超卖）；
  - 空头信号：三指标各自 ≥ (1−tail) 分位（刚涨过/超买）。
  - tail ∈ {0.2, 0.3, 0.4} 在搜索段扫描。
- **五个配置族**（每族扫描 tail 后按"合并搜索 win5 最高且搜索 n ≥ 200"冻结）：
  1. **TRIO-AND**：三条件同时对齐；
  2. **TRIO-VOTE**：至少 2/3 对齐；
  3. **TRIO-SCORE**：三指标按标的 z 分（搜索段统计）取均值的方向对齐分数，
     门槛 = 该标的搜索段信号对齐分数的 (1−tail) 分位；
  4. **FIVE-AND**：TRIO-AND 且（atr_norm ≥ 中位 或 vol_z ≥ 中位）（中位按标的搜索段全事件，第四遍 OR q=0.5 同一波动门）；
  5. **FIVE-STRICT**：TRIO-AND 且 atr_norm ≥ 中位 且 vol_z ≥ 中位。
- **参照**在本遍同程序内重算：无门基线、四遍的 vol OR q=0.5 门，
  结果与第四遍报告逐值一致（基线 51.7%/52.5%，vol OR 52.2%/51.9%），口径可比性确认。
- **扫描量**：合并搜索扫描 15 个配置（5 族 × 3 tail），冻结 5 个，
  每个冻结配置在 8 个范围（合并 + 7 标的）× 2 段评估，另含剂量-反应表。

## 三、扫描结果（搜索段，合并）

| 族 | tail=0.2（n / win5） | tail=0.3（n / win5） | tail=0.4（n / win5） |
|---|---|---|---|
| TRIO-AND | 280 / **54.3%** | 541 / 51.9% | 770 / 52.7% |
| TRIO-VOTE | 930 / 52.5% | 1233 / 52.6% | 1402 / **52.9%** |
| TRIO-SCORE | 309 / **52.8%** | 462 / 52.2% | 614 / 51.8% |
| FIVE-AND | 247 / **54.7%** | 460 / 52.6% | 624 / 53.2% |
| FIVE-STRICT | 97 / 52.6% | 150 / 52.0% | 199 / 53.8% |

注：FIVE-STRICT 三个 tail 的搜索 n 全部 < 200（最大 199），达不到冻结下限；
按预案冻结其样本量最大者（tail=0.4）并在此标注——该族样本先天不足，
其任何数字都只能当参考。其余四族均满足下限。搜索段各族最优值
（54.3% / 54.7%）相对基线 51.7% 的表面 lift 只有 +2.6~+3.0 个百分点，
且都出现在样本最小的 tail=0.2 配置上——是典型的"切得越碎、表面越好看"。

## 七、局限与注意事项

- **三指标不是三票**：mom_10m、rsi14_1m、rsi14_1h 同在第三遍测出的
  16 指标冗余簇内（RSI/%B/mom 家族），彼此高度相关。"3/3 对齐"与"1/3 对齐"
  的信息差远小于名义票数差，VOTE/AND 的区分度先天有限——本遍结果
  （剂量-反应平坦）与这一点相符。
- **ρ≈−0.04 的量级提醒**：三个指标各解释不到 0.2% 的收益方差，
  全事件口径尚且如此；信号子集（已被 prob 预筛过一遍）里残余更少。
  本遍把它们做成门后测不到增益，与相关强度量级一致，不构成对第三遍结论的否定，
  构成的是"这点相关不够做成可交易的门"的实证。
- 验证窗仍只有 3.51 天；冻结后逐标的 n 多在 10–190，标准误 ±4–14 个百分点，
  本遍所有否定性判定基于合并集（n 125–922），逐标的升降不单独下结论。
- 相邻事件结算窗相接、特征高度相关，有效样本量低于名义 n，CI/z 仅作量级参考。
- FIVE-STRICT 未达冻结样本下限（搜索 n 最大 199 < 200），已按预案冻结并标注，
  其结果权重应低于其余四族。
- 毛胜率不计摩擦：5 分钟 |ret5| 平均约 0.06–0.07%，离净口径比 10 分钟更远，此处只作尺度提醒。

## 八、底线

五遍研究至此形成完整链条：模型 prob 是唯一的方向来源；atr_norm / vol_z 管幅度；
mom_10m / rsi14_1m / rsi14_1h 的均值回归相关真实但已被 prob 吸收，
做成外层方向对齐门后，5 分钟口径下验证增益为零（最好的一族只是"几乎不过滤"时与基线打平）。
**在本数据与现行模型上，外层门的搜索空间可以认为已经穷尽**；
若还要推进，剩下的路只有两条：按 5 分钟标签重训模型，或用记录器积累的前向数据
做真正的事前验证。两者都不在本遍范围。
