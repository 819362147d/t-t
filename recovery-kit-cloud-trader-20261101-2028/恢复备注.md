## 回滚步骤

先停掉在跑的实盘进程，再按需要恢复对应层级，最后重启。

恢复桶门层（回到 7 币种无桶门；main.py 同时回到旧触发逻辑）：

```bash
cd ~/workspace/cloud-trader
cp config.py.bak-20261101-bucket config.py
cp main.py.bak-20261101-bucket main.py
cp live_engine.py.bak-20261101-bucket live_engine.py
```

只恢复触发层（保留 4 币种 + 桶门，仅把触发改回旧逻辑）：

```bash
cd ~/workspace/cloud-trader
cp main.py.bak-20261101-trigger main.py
```

重启实盘（密钥只经环境变量提供，本包不含任何密钥）：

```bash
MEXC_ACCESS_KEY=<环境变量注入> MEXC_SECRET_KEY=<环境变量注入> \
  .venv/bin/python main.py --live --i-understand-live-risk
```

`runtime/live_state.json` 不在本包内、回滚时也不要动它，进程会按其中记录继续跟踪未平仓位。
