# 桶组合币种胜率研究日记

cloud-trader 事件模型（LightGBM 10 分钟方向概率）+ 指标门控研究线全记录。
研究全程只读 MEXC 公开 K 线，未下单、未用密钥；六份研究报告原文收录于本包 `研究报告/`。
统一口径：事件锚定 5 分钟 bar 收盘，离线概率与实盘逐位一致；时间先 60% 搜索 / 后 40% 验证，
所有阈值只在搜索段选、冻结后原样验证；胜率分毛（方向对）与净（方向涨幅越过摩擦 0.21%–0.28%）。

## 2026-11-01 下午 — 14 天回填与第一遍研究（净口径）

- 做了什么：回填 14 天 MEXC 合约 K 线（7 标的 + ETH 参考，零缺口），构建 17,717 个事件
  （10 分钟结算），做阈值扫描 + 约 2,562 个指标过滤配置的搜索/验证。
- 头条数字：基线（0.55/0.45）毛胜率 53.8% / 54.9%，但**净胜率只有 3.5% / 4.7%**；
  唯一过验证的过滤是 `mom_10m ≥ 0.135%`，验证净胜率 **12.05%**（n=166，约 47 信号/日）。
- 结论：方向不差，是摩擦吃人——10 分钟涨幅中位数仅 0.045%、90 分位 0.196%，
  而摩擦门槛 0.21%–0.28% 约等于 90 分位。调阈值无样本外增益。逐标的：BTC 最强
  （净 7.2% / 6.6%），XAU 方向真有效，SPY / QQQ / BNB 列为剔除候选。
  （报告：`研究报告/REPORT.md`）

## 2026-11-01 傍晚 — 纯胜率重跑（不计摩擦）

- 做了什么：同一数据集、同一切分，把目标换成纯毛胜率重跑阈值与过滤搜索（2,742 个配置）。
- 头条数字：合并基线毛胜率 53.8% / **54.9%**（验证 95% CI 51.9–57.9%，方向 edge 统计上真实，
  但验证段平均方向涨幅 −0.004%，赢多次、每次赢得小）；**黄金验证段 73.0%**（n=89）且多空双向都显著；
  BTC 58.1% 但优势几乎全在做多（多头 76.9%，空头 50.5% 是抛硬币）；**BNB 两段都 <50%**。
- 结论：阈值照样调不动（维持 0.55/0.45）；毛口径的过滤都很弱（最好仅 +2~3 个点）。
  排名：XAU > BTC > TSM > USOIL > QQQ > SPY > BNB。
  （报告：`研究报告/REPORT_GROSS.md`）

## 2026-11-01 傍晚 — 多指标相关性研究

- 做了什么：31 个指标与结果的 Spearman 相关（方向 / 涨幅两路）+ 互信息；
  11,625 个双指标五分位状态组合搜索；指标间冗余矩阵；深度-3 GBM 交叉核对。
- 头条数字：全场唯一强而稳的相关是 **atr_norm ↔ 涨幅大小：ρ = +0.335 / +0.499，7/7 标的同号**；
  方向相关只有 mom_10m、rsi14_1m、rsi14_1h 三条弱负相关（ρ≈−0.04，均值回归）；
  双指标组合冻结验证**非日历类幸存者 0 个**，GBM 样本外 AUC = 0.498（抛硬币）；
  37 对 |ρ|≥0.7 全挤在一个 16 指标冗余簇里，31 个指标有效维度只有约 7~8 个。
- 结论：指标决定"动多大"、不决定"往哪动"；那点弱方向信息已被模型概率吃完，
  同簇内继续排列组合没有出路；波动门有效（第一遍）是因为涨幅能越过摩擦，不是方向变准。
  （报告：`研究报告/REPORT_CORR.md`）

## 2026-11-01 晚 — 5 分钟事件 + atr_norm / vol_z 主导门

- 做了什么：结算改 +5 分钟（ret5），atr / vol_z 四种门（单 atr、单 vol_z、AND、OR）
  分位阈值搜索段选优、冻结验证（128 个配置）。
- 头条数字：基线 win5 51.7% / 52.5%（比 10 分钟口径薄）；**四个门验证全部跑输基线**
  （51.4% / 49.8% / 51.3% / 51.9%）；AND 门把平均 |ret5| 筛到基线 2 倍（0.146% vs 0.073%）
  但方向胜率反而降。win5 对 atr_norm 是驼峰：Q1 最差 47.6%、Q2 最好 56.5% / 61.9%、Q5 回落 49%。
- 结论：幅度门在毛胜率问题上做主导无效；5 分钟的瓶颈在模型标签（模型按 10 分钟方向训的）。
  （报告：`研究报告/REPORT_5MIN.md`）

## 2026-11-01 晚 — 五指标合跑（回归三件套 × 波动门）

- 做了什么：在 5 分钟口径上把 mom_10m、rsi14_1m、rsi14_1h 按信号方向对齐做门，
  与 atr / vol_z 门组合成五个配置族（全对齐 / 投票 / 打分 / 合体 / 严格），尾部档位搜索后冻结验证。
- 头条数字：**五族验证 win5 全部 ≤ 无门基线 52.5%**（51.9% / 52.5% / 51.2% / 52.0% / 50.4%）；
  剂量-反应：对齐个数 0/1/2/3 → 52.9% / 53.4% / 52.6% / 51.7%，非单调、全对齐反而最低；
  随对齐单调上升的只有涨幅大小。另暴露结构问题：固定阈值遇分布漂移会样本归零（USOIL 全对齐门验证 n=0）。
- 结论：三件套的均值回归相关真实存在，但已被模型概率吸收，做成门增益为零；门越严越差。
  （报告：`研究报告/REPORT_5MIN_TRIO.md`）

## 2026-11-01 晚 — 十分位细桶精细化

- 做了什么：回应"五分位桶太粗、指明性差"——改十分位 + 1%~10% 极端尾细格 +
  atr×vol 10×10 交叉热力表 + 30 个冻结峰值带验证（约 1,640 次桶/带统计）。
- 头条数字：**30 个冻结带 0 个通过**（标准：验证 CI 不含基线且方向涨幅为正）；
  vol_z 十分位两段全反转（搜索 D10 最好 59.1% → 验证 D10 最低 47.5%）；
  唯一近失是 **mom_10m 的 win10 D5 中段带：验证 62.3%（n=122）**，但 CI 仍盖着基线 54.9%，
  只能算待前向复验的假设；细桶在验证段因分布漂移大面积塌陷（如 atr_norm D1=315 人 / D3=17 人）。
- 结论：不是桶太粗，是胜率曲面本来就没有峰；细化只是把噪声切得更碎。
  （报告：`研究报告/REPORT_BUCKETS.md`）
