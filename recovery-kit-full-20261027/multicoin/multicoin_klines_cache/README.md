# multicoin_klines_cache/（K 线磁盘缓存）

本目录在恢复包里是空的——679 个 `*.npz` 缓存文件（约 35MB）**没有打进包**。

原因：缓存是纯加速用的临时数据，币安已收盘 K 线不可变，丢了可以自动重建。
恢复后第一次跑多币种脚本时，`multicoin_klines_cache.py` 会对没有缓存的币种自动全量拉取并写回本目录，
之后每轮只拉最新 40 根 1m / 16 根 5m。首轮约 60–70 秒，之后稳定在约 60 秒左右。

缓存损坏、缺失、过期都会自动全量重拉（fail-open），绝不会因此无预报或错预报。
如需手动清空缓存，删掉本目录下全部 `*.npz` 即可。
