## 一句话结论

**数据不可行（本会话内）——不是信号被证伪，是数据没拿全。** Binance 官方归档根本没有 USDⓈ-M
爆仓数据集；唯一找到的免费全历史源（CryptoHFTData 的 `binance_futures` 爆仓归档）确认覆盖整个
实验窗口（349 天），但其无 key 免费下载在约 500 个文件后触发持续限速，本会话只完整拉到
**10.5 天**切片。≥90 天回测因此未执行（10.5 天无法复刻 6 折 walk-forward 协议，硬跑即造假）。
事件分层在切片上做了探索性试算：预设口径（z≥3）的大爆仓事件 **0 个**，放宽到 z≥2 仅 26 个，
延续率 0.538（n=26，95%CI [0.355, 0.712]）——**无结论**。爆仓假设既未被证实，也未被证伪。

### 限速实测（决定本会话成败的一条）

- 下载器 32 并发开拉全窗口 16,738 个小时文件（349 天 × 24h × 2 标的）：前段约 2 文件/秒，
  拉到 **505 个文件**（BTC 252 + ETH 253，恰好是 2025-11-02 07:00 ~ 2025-11-12 22:00 的
  **连续完整 10.5 天**，0 缺失 0 失败）后，下载端点（302 跳转到 Cloudflare R2 签名链接）
  开始持续 tarpit：单文件耗时从 ~1.5 秒恶化到 36 秒乃至 30~45 秒超时 0 字节。
- 停掉下载器后多次探针（冷却约 15 / 20 / 50 / 70 分钟）均未恢复；同一 egress 下 Binance Vision
  下载始终 1.5 秒正常，排除本机网络故障。定性：**免费档按 IP 的配额/限速（疑似按天），
  本会话内无法绕过，也不尝试绕过。**
- 文件格式小坑：同数据集两种封装混存——部分文件是裸 parquet（魔数 `PAR1`），部分是
  zstd 套壳 parquet（魔数 `28b52ffd`），读取需按魔数分流（转换脚本已处理）。

### 数据语义的硬伤（对任何来源都成立，必须先于结论知道）

Binance USDⓈ-M 的 forceOrder 流是**快照采样**：官方文档明示「每个标的每 1000ms 只推送
最新一笔爆仓单」。即任何从公开流采集的爆仓历史（包括 CryptoHFTData 和自建采集）都是
**抽样下限**：安静时段接近全量，**瀑布期每秒最多记 1 笔、删失最严重**——恰好是本实验
最想测的时段。特征（窗口爆仓额、失衡、z 分）只能当相对强度用，绝对额系统性低估。
这一条不否定实验，但决定了增益上限先天打折，且未来若影子化，线上特征与回测口径同源、可比。

## 实时自采（websocket forceOrder）的评估（简版）

- 通道：`wss://fstream.binance.com` 走 443，协议层可行；但本机 fapi REST 已被 451 地域封锁，
  ws 流是否同样按 IP 封锁未实测（REST 已封，ws 大概率同策略，接入前需先验一条连接）。
- 语义：同上快照采样（1 笔/秒/标的封顶），自采与第三方归档同源同删失，不更全。
- 日历账：从现在（2026-10-21）起采，攒满 90 天要到 **2027-01-19**；攒到与现协议可比的
  ~350 天约 **2027-10**。且 FEAT3 价格特征窗止于 2026-10-16，届时还要同步延长特征窗重训，
  不是「攒够天数就能直接套现协议」。
- 运维：本 VM 会被平台回收重启（微信桥看门狗日志多次记录），长连接采集必须配看门狗 +
  断点标记 + 缺口清单，否则缺口会静默污染特征。
- 结论：**能搭，但回报周期以季度计，不建议作为主线**；优先级低于「拿到归档全量」。

## 诚实下一步（按性价比排序）

1. **最优解锁：用户侧注册 CryptoHFTData 免费 key（$0、无需信用卡，站方 FAQ 明示免费档含
   API 访问），经 Secure Vault 给到助手**，即可走 API/SDK 拉全量（绕开无 key 单文件档的
   tarpit），随后 `exp4_wf.py liq/allliq` 原样跑三组对比 + 全窗口事件分层，一次闭环。
   助手不能代注册账号，所以这一步卡在用户侧一个动作。
2. 次选：等配额重置（若按天）后限速分日续拉——约 500 文件/天 → 全量 16,738 个需约 34 天，
   只拉最近 120 天（5,760 个）也要约 12 天，且窗口化后折定义要改、结论降级，不划算。
3. 爆仓线就此挂起，不进影子、不动现网。优化主线按既定纪律继续：现网实盘攒满 30 个已结算、
   影子 v1/v2 并行记账。爆仓是「最后一个没试的新信息源」，本实验的产出是把它的**获取路径
   和语义边界**钉死了：路径只剩 key 这一把钥匙，语义上限是「采样下限数据」。
4. 顺带钉死两个伪源头供以后免查：Binance Vision 没有 UM 爆仓归档（CM 的 2024-10 已终止）；
   OKX 官方 REST 爆仓深度只有约 24 小时；CoinGlass 需 key；Bybit 官方公开归档无爆仓。
