# 影子 v3·精选版上线说明（2026-10-21）

## 一句话

影子 v3 = 影子 v2（现网基线模型 + 规则门控）的子集过滤版：只记「做多 & 亚盘 & 规则同向」的最精选信号，账本 shadow3-alerts.jsonl，只记账、不推送、不交易。

## 精选触发条件（三条全满足才记账）

- 只做多：现网基线模型（lightgbm_10min.txt + FEAT3 31 特征）prob_up ≥ 0.55，看跌一律不记，dir 恒为 UP。
- 规则同向：均值回归规则 mr ≥ 1（mr = −(z(rsi14_5m) + z(boll_pctB_1m))/2，z 统计沿用 shadow_rulegate_meta.json 的全量 350 天固定 mean/std，与 v2/实验三一致）。
- 时段过滤：候选时刻（bar 时间，UTC）落在 00:00–08:00（亚盘）。

防重复：沿用 v2 的 state 文件逻辑（shadow_select_state.json 记住已处理候选时刻），无方向冷却去重。字段与 v2 一致：t/sym/dir/prob/mr/close。

## 回测依据（线索级，不是定案）

- 实验一（opt-exp1-20261020.md）：「做多 & 亚盘（UTC 00–08）」样本外胜率 0.630，n=405。
- 实验二（opt-exp2-20261020.md）：同一子集 0.650，n=477。
- 两个数字都来自事后子集拆分，存在多重比较/过拟合风险，只能算线索；这正是 v3 只进影子、不动现网的原因。

## 与 v1/v2 的关系

- v1（全组合）：新特征全组合模型，已判负（0.55 档影子实盘 0.468），仅留高档位观察。
- v2（规则门控）：基线模型双向触发 + mr 同向门控，记 shadow2-alerts.jsonl，攒 ≥30 个已结算判线索真伪中。
- v3（精选版）：v2 的子集——方向只留 UP、时段只留亚盘。触发频率会明显低于 v2（每天最多亚盘 8 小时窗口内的候选），攒样本更慢，这是精选的代价。

## 判定标准

- 攒够 ≥30 个已结算预报后结算胜率。
- 过关线：胜率明显高于现网同期实盘水位（且不是靠个位数样本撑起来的），才考虑给现网加这层精选过滤；不过关就关掉，不反复调条件凑数字。
- 结算口径与现网一致：候选时刻收盘价 vs 10 分钟后收盘价比方向。
