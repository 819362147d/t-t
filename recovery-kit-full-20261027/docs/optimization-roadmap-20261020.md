# 10 分钟预报优化路线图（2026-10-20）

用户授权：助手自主规划优化/测试/修正路线，目标胜率 68%。只预报不交易，红线不变。

## 诚实边界（先说清）
- 历史四轮回测样本外上限约 0.63–0.65（LightGBM K=1000 档 0.627），全量信号打到 68% 大概率不现实。
- 能冲 68% 的现实路径只有一条：**高选择性**——更高阈值 + 行情 regime 过滤，只做最有把握的子集。代价：信号数量明显变少、攒样本验证更慢。
- 最大敌人是过拟合：对同一份 350 天数据反复调参， 回测数字会虚高、实盘打回原形。所有结论必须 walk-forward（用过去训、未来验，多折滚动），最终 holdout 只验一次。

## 阶段一：基线复核与选择性扫描（先行）
- walk-forward 重估现模型真实样本外水位（多折）。
- 阈值扫描：0.55 / 0.58 / 0.60 / 0.62 各档的样本外胜率与 n。
- regime 过滤：波动率分位、趋势强度、时段（亚/欧/美盘、数据窗口）分层胜率。
- 产出：每档「胜率 + n + 信号频率」，挑出有望 ≥0.65 的组合进阶段四影子。

## 阶段二：特征扩展
- OI 与资金费率：走 Binance fapi 公开接口重试（此前三路被禁，再试不同路径）。
- 盘口失衡（depth imbalance）、主动买卖比（aggTrades）。
- 跨周期背景：15m / 1h / 4h 的 RSI、动量、波动状态作上下文特征。
- 已实现波动率、振幅分位、日内时段哑变量。

## 阶段三：模型层
- LightGBM 受控调参（小网格 + walk-forward 选，不许对验证集反复试）。
- 概率校准（isotonic/Platt），让 0.60 真的是 0.60。
- 集成：LightGBM + LR + 均值回归规则投票。
- 标签试验：triple-barrier（要求涨幅越过噪声带才算赢），减少平局噪声。

## 阶段四：影子并行
- 候选模型只记账不推送，与现网同场跑；各自结算胜率。
- 影子攒够 ≥30 个已结算、且胜率明显高于现网基线，才进阶段五。

## 阶段五：晋级 / 回滚
- 晋级：换现网模型，旧模型保留可回滚。
- 回滚线：换后实盘胜率跌破现网历史基线（0.588 起步参考）且 n≥20，自动建议回滚并报告用户。

## 纪律
- 现网在实盘记账攒满 30 个已结算前不换模型（用户 2026-10-18 定的规矩优先）。
- 每个胜率数字必须附 n；小样本结论标注「未定」。
- 有阶段性结论（正或负）再向用户汇报，不刷屏。
